

# 一周食单 · 好好吃饭

一个纯前端的家常菜谱工具，内置 181 道菜，帮你每周生成菜单、采购清单和做法，省去每天想“吃什么”的烦恼。

所有数据存在浏览器本地，不联网，不收集任何信息。

---

## 它能做什么

### 1. 生成一周食单
点击“生成本周食单（7道）”，系统会自动选出 7 道菜：
- 固定出 4 道：鸡蛋、鱼类、鸡肉，以及肉丝/肉馅（单周肉丝、双周肉馅）
- 轮换出 3 道：从虾类、牛羊肉卷、牛肉（鲜）、豆制品、凉菜、经典大菜这 6 个分类中，按 8 周计划表轮转

生成后自动勾选菜品，结果区会显示：
- 已选菜品汇总
- 采购清单（自动合并相同食材，按肉类/水产/蔬菜/其他分类）
- 食材复用建议（哪些食材可以一起买、一起备菜）
- 每道菜的详细做法（主料、辅料、调料、步骤、关键点）

### 2. 采购清单 + 做法
你手动勾选任意菜品，点击“生成采购清单 + 做法”，效果同上，但基于你选的菜生成。

### 3. 快速选菜
页面中间按分类列出所有菜品，每个菜旁边显示它出过的周数（升序排列），方便你了解哪些菜最近出过、哪些菜很久没出了。支持全选和清空。

### 4. 不想做饭
点击“不想做饭”，从“抚慰主食”分类中随机推荐一道（如皮蛋瘦肉粥、葱油拌面等），显示做法和一句抚慰语。支持换一个、确认选择，也可导出 HTML 或 PNG。

### 5. 导出
在结果区或不想做饭弹窗里，都可以导出：
- HTML：导出成一个完整的网页文件，用浏览器打开，样式完整，适配手机
- PNG：导出成图片，宽度 420px，2 倍清晰度，适合发微信或保存

### 6. 重置轮换
点击“重置轮换”，清空所有历史周数和轮转指针，所有菜品回到“未出”状态，从第 1 周重新开始。

### 7. 搜索
顶部的搜索框可以按菜名或主料搜索，快速找到你想看的菜。

### 8. 手机安装（PWA）
部署到 HTTPS 服务器后（Netlify / Vercel / GitHub Pages），手机浏览器打开，地址栏会出现“安装”按钮，点一下就像 App 一样装到桌面，离线也能打开。

## 数据格式（dishData）

你需要在代码里找到 `var dishData = [];`，按以下格式粘贴你的菜谱数据：

```javascript
var dishData = [
  {
    cat: "分类名",  // 如 "肉丝"、"鸡蛋"、"鱼类"
    items: [
      {
        n: "菜名",
        m: [{ name: "食材", amount: "用量" }],
        s: "来源或参考",
        t: "耗时",
        z: ["主料列表"],
        f: ["辅料列表"],
        l: ["调料列表"],
        o: ["操作步骤"],
        k: "关键点"
      }
    ]
  }
];
```

每个分类下可放多道菜，系统会按分类内部的轮转指针依次取菜，保证同一道菜不会连续出。

---

## 分类说明

内置分类及默认轮转规则：

| 分类 | 出菜规则 |
|------|---------|
| 鸡蛋 | 每周 1 道（固定） |
| 鱼类 | 每周 1 道（固定） |
| 鸡肉 | 每周 1 道（固定） |
| 肉丝 / 肉馅 | 隔周交替，每周 1 道 |
| 虾类、牛羊肉卷、牛肉（鲜）、豆制品、凉菜、经典大菜 | 按 8 周计划表轮转，每周从中出 3 道 |

每个分类内部按指针顺序取菜，指针存在 localStorage 里，刷新页面不丢失。

---

## 运行方式

双击 `index.html` 在浏览器中打开即可。所有数据存本地，无后端依赖。

---

## 部署到手机

1. 把 `index.html` 部署到任意支持 HTTPS 的静态托管平台：
   - Netlify（拖拽上传）
   - Vercel（拖拽上传）
   - GitHub Pages
2. 手机浏览器打开 HTTPS 链接
3. 地址栏会出现“安装”按钮，点击安装到桌面

---

## 数据存储

| 键名 | 存什么 |
|------|--------|
| `week_menu_history` | 每周出菜记录、各分类轮转指针 |

清除浏览器缓存不影响，但**清除网站数据**会导致所有记录丢失。

---

## 浏览器兼容

- Chrome / Edge / Firefox 最新版
- 手机端建议用 Chrome 或 Edge
- 不支持 IE

---

## 已知限制

- 导出 PNG 依赖 html2canvas CDN，需要网络
- PWA 安装需要 HTTPS 环境，本地 `file://` 不支持
- 菜谱数据需要手动粘贴到代码中，没有后台管理界面
- 不是真正的一周，只是每次随机生成固定数量的菜，你可以每周点一次，也可以一天点好几次
